# Сайт Aedisyn

Статичний сайт студії. Збірки не потребує — це чистий HTML, CSS і модулі ES.

## Структура

```
.
├── index.html
├── assets/
│   ├── css/
│   │   ├── tokens.css      кольори, радіуси, шрифти, обидві теми
│   │   ├── base.css        скидання, типографіка, аврора й зерно
│   │   ├── components.css  шапка, кнопки, картки, значки
│   │   └── sections.css    герой, продукти, можливості, завантаження
│   └── js/
│       ├── main.js         точка входу
│       ├── theme.js        світла й темна тема
│       ├── reveal.js       поява при прокрутці, смужка прогресу
│       └── projector.js    демонстрація слайда в героїблоці
└── README.md
```

Правило одне: **кольори оголошуються тільки в `tokens.css`**. Якщо десь
знадобився новий колір — він додається туди, а не в місце використання.
Інакше друга тема почне розсипатися по одному місцю за раз.

## Запуск

Модулі ES не працюють з `file://` — потрібен будь-який локальний сервер:

```bash
python3 -m http.server 8000
# або
npx serve
```

Далі http://localhost:8000

## Коли з'явиться StreamStats

У `index.html` знайдіть картку з класом `card--soon`:

1. приберіть `card--soon` з `class`;
2. замініть `<span class="tag tag--live">Скоро тут</span>`
   на кнопки завантаження, як у сусідній картці.

Решта сторінки не змінюється.

## Швидкодія

Сайт свідомо тримається без важких ефектів. Що НЕ варто повертати:

| Прийом | Чому прибрано |
|---|---|
| `filter: blur()` на великих плямах | розмиття пів-екрана перемальовується щокадру |
| анімовані шари фону | те саме, але ще й безперервно |
| `backdrop-filter` у шапці | перераховується на кожен кадр прокрутки |
| SVG-зерно на 200% екрана | учетверо більше пікселів, ніж видно |
| тіні з розмиттям понад 60px | дорого перемальовуються разом з елементом |
| `transform` на картках при наведенні | змушує перераховувати розкладку сусідів |

Фон тепер — статичні градієнти на `body`. Малюються один раз.

Якщо додаєте нову анімацію, анімуйте лише `opacity` і `transform`,
і лише на невеликих елементах.

## Доступність

Це не формальність — сайтом користуються з проектора й з телефона:

- обидві теми тримають контраст тексту не нижче 4.5:1;
- фокус з клавіатури видно завжди (`:focus-visible`);
- `prefers-reduced-motion` вимикає аврору, появу й автопоказ слайдів;
- проектор у героїблоці керується з клавіатури, кожна кнопка підписана.

Змінюючи оформлення, перевіряйте ці чотири пункти.
